# Tanglin Rd Stitch Design System

Design source: Google Stitch-style AI-native product canvas.

## Intent

Tanglin Rd should feel like a high-trust campaign operations room, not a generic SaaS admin panel. The interface combines creator marketplace energy with financial operations clarity.

## Visual Language

- Canvas-first: layered backgrounds, soft grid fields, floating panels, and clear working zones.
- Editorial density: large confident headings, compact operational tables, and metric cards that feel like live instruments.
- Warm precision: marigold and lime accents for creator energy, stone and ink for trust, cyan for AI tooling.
- No purple default and no dark-mode-first aesthetic.

## Tokens

- Ink: `#17211c`
- Stone: `#403b35`
- Paper: `#fffaf0`
- Surface: `rgba(255,255,255,0.78)`
- Marigold: `#f4b000`
- Lime: `#a3e635`
- Cyan: `#67e8f9`
- Coral: `#fb7185`

## Patterns

- Cards use glassy white surfaces with stone borders and subtle colored glows.
- Metric cards include a live signal dot and strong number hierarchy.
- Tables should feel like review queues, with warm headers and comfortable row spacing.
- Shell navigation uses compact canvas chips rather than heavy sidebar blocks.
- Forms use rounded fields, visible focus rings, and clear primary/secondary action contrast.

## Interaction

- Page loads use subtle `rise-in` motion.
- Cards lift slightly on hover only where it does not imply a destructive action.
- Buttons remain tactile and explicit; no hidden icon-only critical actions.

## Accessibility

- Maintain strong text contrast on surfaces.
- Use semantic tables and links.
- Avoid relying on color alone for status; status badges include text labels.
