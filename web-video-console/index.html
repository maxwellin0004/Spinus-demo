                      User Guide
                      
    本地 AI 视频生产步骤
    
                      
    这个工作台支持单条视频和批量生成。日常使用可以不绑定 Codex session，直接从任务配置进入生成计划、配音、渲染和 Screen QA。
    
                    
    
                    
                  
    
                  
    
                    
    
                      01
                      
    选择账号和模板
    
                      
    账号决定口吻、平台、CTA 和限制项；模板决定画面结构、比例、推荐时长和 Remotion composition。它们只影响新任务默认配置，不会改动当前 activeJob。
    
                    
    
                    
    
                      02
                      
    创建单条任务
    
                      
    点击“新建单条任务”，填写视频主题、时长、平台和额外要求。创建后中间栏会显示当前任务、生产步骤和产物状态。
    
                    
    
                    
    
                      03
                      
    不绑定 session 直接生成
    
                      
    Session 是可选的。没有绑定 session 时，仍然可以点击“生成计划”“配音”“渲染”或“一键生成 MP4”，前端会走本地生产链路。
    
                    
    
                    
    
                      04
                      
    一键生成 MP4
    
                      
    点击“一键生成 MP4”会自动执行：生成计划、生成 TTS 与时间轴、绑定 Remotion、渲染视频、Screen QA。运行中按钮会锁定，避免重复触发。
    
                    
    
                    
    
                      05
                      
    进入脚本审阅模式
    
                      
    在设置中选择“脚本审阅后继续”。生成计划后先检查脚本、字幕和镜头摘要，再决定是否继续配音和渲染。
    
                    
    
                    
    
                      06
                      
    用 AI 修改脚本
    
                      
    展开 Session 区并绑定当前任务后，可以在对话框里要求 AI 修改 hook、结构、字幕或 CTA。修改建议会保留在当前任务上下文里。
    
                    
    
                    
    
                      07
                      
    QA 失败的含义
    
                      
    Screen QA 用于阻止提示词、内部元数据或错误文案进入画面。QA 未通过时不能导出，需要重新生成计划或修正脚本后再渲染。
    
                    
    
                    
    
                      08
                      
    使用批量生成
    
                      
    进入“批量队列”，按项目、活动、选题池组织任务。可以多个选题配多个账号，批量运行计划、配音和渲染，并查看失败重试队列。
    
                    
    
                    
    
                      09
                      
    查看历史任务和产物
    
                      
    进入“历史任务”查看过去的任务、状态、视频、封面帧和下载入口。可以归档旧任务，保留可复用产物和日志。
