# Tanglin V1 用户操作文档

本文档说明 Tanglin V1 平台中三类用户的使用方式：

- 商家：发布推广任务、审核 KOL、审稿、验收发布链接、查看报表和账单。
- KOL：维护资料和社媒账号、申请任务、提交草稿、提交发布链接、提现。
- Admin：审核账号、确认付款、处理争议、结算、配置平台规则。

本地访问地址：

```text
http://127.0.0.1:3000
```

## 1. 用户角色概览

### 1.1 商家

商家适合自助发布小额推广任务。第一版重点是快速发任务、让 KOL 自由申请、商家手动审核和验收。

商家主要使用页面：

- `/brand`：商家仪表盘
- `/brand/profile`：品牌资料
- `/brand/campaigns`：Campaign 列表
- `/brand/campaigns/new`：创建 Campaign
- `/brand/campaigns/[id]`：Campaign 详情和 KOL 申请审核
- `/brand/campaigns/[id]/submissions`：内容草稿审核
- `/brand/campaigns/[id]/proofs`：发布链接验收
- `/brand/campaigns/[id]/reports`：Campaign 报表
- `/brand/billing`：账单、付款凭证、余额和退款申请
- `/brand/notifications`：站内通知

### 1.2 KOL

KOL 主要负责维护社媒账号、申请任务、按 brief 交稿和提交发布链接。

KOL 主要使用页面：

- `/creator`：KOL 仪表盘
- `/creator/profile`：个人资料和社媒账号
- `/creator/marketplace`：任务大厅
- `/creator/tasks/[id]`：任务详情和申请
- `/creator/my-tasks`：我的任务
- `/creator/my-tasks/[id]`：任务履约详情
- `/creator/content-studio/[applicationId]`：提交内容草稿
- `/creator/wallet`：钱包和提现
- `/creator/notifications`：站内通知

### 1.3 Admin

Admin 负责平台运营、审核、资金确认、争议处理和配置规则。

Admin 主要使用页面：

- `/admin`：Admin 仪表盘
- `/admin/social-accounts`：社媒账号审核队列
- `/admin/payments`：付款、结算、提现、退款处理
- `/admin/disputes`：争议处理
- `/admin/settings`：平台配置和 SLA 自动处理
- `/admin/compliance`：规则中心
- `/admin/reports`：全局报表
- `/admin/audit`：操作日志
- `/admin/staff`：Admin 权限管理

## 2. 商家操作流程

### 2.1 注册和完善品牌资料

1. 打开首页，进入注册页面。
2. 选择商家身份注册。
3. 登录后进入 `/brand/profile`。
4. 填写品牌名称、公司名称、联系人、邮箱、国家、行业、品牌介绍等资料。
5. 保存后等待平台审核。

注意：

- 第一版允许商家先创建任务，但在付款托管前应完成轻量认证。
- 品牌名和产品名默认对 KOL 公开。
- 联系邮箱只处理一般问题，资金和任务争议必须在系统内处理。

### 2.2 创建 Campaign

入口：`/brand/campaigns/new`

创建向导分为 6 步：

1. 推广目标
2. 目标 KOL
3. 平台任务
4. 内容要求
5. 素材与验收
6. 预算与发布

#### 第 1 步：推广目标

填写：

- Campaign 名称
- 产品/项目名称
- 产品或活动链接
- 行业分类
- 推广目标
- CTA
- 开始时间
- 结束时间
- 产品介绍 brief

也可以使用系统模板：

- 小红书图文种草
- 抖音短视频测评
- B站深度体验
- 微博新品扩散

如果选择高风险行业，系统会显示软提示，但不会阻止创建任务。

#### 第 2 步：目标 KOL

填写：

- 主要国家/地区
- 内容语言
- 目标人群
- 默认最低粉丝数

默认规则：

- 只有已验证社媒账号的 KOL 可以申请。
- 商家可以勾选允许未验证社媒账号申请。

建议第一版默认不要放开未验证账号，除非商家愿意自己承担筛选成本。

#### 第 3 步：平台任务

每个平台单独配置：

- 平台
- 内容形式
- 招募人数
- 每人奖励
- 最低粉丝数
- 交稿截止时间
- 发布截止时间
- 平台补充要求

支持平台：

- 小红书
- 抖音
- 视频号
- B站
- 微博

系统会按平台任务自动生成任务包，不需要 Admin 手动拆任务。

#### 第 4 步：内容要求

填写：

- 必须包含内容
- 禁止表达
- 画面/素材要求
- 推荐 Hashtag
- 是否需要 KOL 先提交草稿

广告披露是强制项，商家不能关闭。

如果勾选需要审稿：

- KOL 必须先提交结构化草稿。
- 商家审核通过后，KOL 才能正式发布。
- 最多支持 2 轮修改。

如果不需要审稿：

- KOL 提交内容后会直接进入发布阶段。

#### 第 5 步：素材与验收

填写：

- Campaign 素材上传
- 外部素材链接
- 商家验收 SLA
- 高金额复核阈值
- 补交宽限期

第一版素材规则：

- Campaign 级素材支持轻量附件和外部链接。
- 不建议上传大视频素材。
- KOL 草稿预览附件默认上限 50MB，可由 Admin 配置。

发布证明规则：

- KOL 只需要提交发布链接。
- 不要求截图、浏览量、点赞量等指标。
- 如果链接失效、删除、不可访问或私密，默认由 KOL 负责。

#### 第 6 步：预算与发布

系统会计算：

- 总名额
- KOL 奖励托管金额
- 平台服务费
- 总预算

第一版资金规则：

- 只支持人民币。
- 只支持固定基础奖励。
- 第一版平台服务费默认为 0，但字段已保留。
- Campaign 总额一次性托管。

发布后：

- 如果商家平台余额足够，系统直接冻结对应金额并发布 Campaign。
- 如果余额不足，Campaign 进入待付款状态，商家需要上传付款凭证，等待 Admin 人工确认。

### 2.3 上传付款凭证和托管资金

入口：`/brand/billing`

商家可以：

- 查看平台余额。
- 查看待付款账单。
- 上传或查看付款凭证。
- 查看平台收据。
- 发起退款申请。

付款确认流程：

1. 商家根据待付款账单线下付款。
2. 商家上传付款凭证。
3. Admin 在 `/admin/payments` 人工确认。
4. 系统把金额计入商家余额。
5. 如果 Campaign 等待托管，系统冻结对应金额并发布 Campaign。

退款规则：

- 未开始任务可退回商家平台余额。
- 已交稿后按规则部分退款。
- 已发布后通常不退。
- 第一版退款优先回到平台余额，不直接线下退款。

### 2.4 审核 KOL 申请

入口：`/brand/campaigns/[id]`

商家可以看到：

- KOL 名称
- 申请任务
- 申请说明
- 发布账号
- 账号验证状态
- 账号粉丝数
- 手填粉丝数
- 账号主页链接

支持两种审核方式：

- 单个通过/拒绝
- 勾选后批量通过/批量拒绝

通过后：

- KOL 进入履约流程。
- 任务名额会被占用。

拒绝后：

- KOL 收到站内通知。
- 名额不被占用。

注意：

- 默认同一个 Campaign 每个 KOL 只能接 1 个任务。
- 如果任务名额已满，无法继续通过申请。

### 2.5 审核内容草稿

入口：`/brand/campaigns/[id]/submissions`

商家可以查看 KOL 提交的结构化草稿：

- 标题
- 脚本/正文
- Caption
- Hashtag
- 封面文字
- 广告披露位置
- 可选预览附件
- 修改轮次
- 历史审核记录

商家可执行：

- 通过
- 要求修改
- 拒绝

要求修改时必须填写说明。第一版最多支持 2 轮修改。

注意：

- 通过后 KOL 才能正式发布。
- 重大修改应要求 KOL 重新提交草稿。

### 2.6 验收发布链接

入口：`/brand/campaigns/[id]/proofs`

商家可以看到：

- KOL
- 平台
- 发布链接
- 发布时间
- 提交时间
- SLA 到期时间
- 当前状态

商家可执行：

- 验收通过
- 拒绝验收

拒绝验收必须填写：

- 结构化原因
- 文字说明

拒绝后：

- KOL 可以在发布截止时间前继续补交。
- 每次验收仍有 SLA。
- 最终仍受发布截止时间限制。

如果商家超过 SLA 未验收：

- Admin 可以在 `/admin/settings` 手动运行 SLA 自动处理。
- 低金额任务会自动通过。
- 高金额任务会进入平台争议处理。

### 2.7 查看 Campaign 报表

入口：`/brand/campaigns/[id]/reports`

报表重点是履约状态，不强调复杂数据指标。

可以查看：

- Campaign 基础信息
- 预算和托管情况
- 平台任务完成情况
- KOL 申请情况
- 草稿状态
- 发布链接状态
- 验收状态
- 结算状态

支持下载 Campaign CSV。

## 3. KOL 操作流程

### 3.1 注册和完善资料

1. 打开首页，进入注册页面。
2. 选择 KOL 身份注册。
3. 登录后进入 `/creator/profile`。
4. 填写昵称、国家、语言、内容领域、简介等资料。

### 3.2 添加社媒账号

入口：`/creator/profile`

填写：

- 平台
- 账号名称
- 账号链接
- 手填粉丝数
- 手填平均播放量
- 内容形式
- 国家
- 语言

提交后：

- 账号进入待审核状态。
- Admin 在 `/admin/social-accounts` 审核。
- 审核通过后账号状态变为已验证。

注意：

- 默认只有已验证账号可以申请任务。
- 如果商家放开未验证账号，未验证账号也可以申请，但商家会看到验证状态。

### 3.3 浏览任务大厅

入口：`/creator/marketplace`

KOL 可以查看正在开放的任务，包括：

- Campaign 标题
- 品牌和产品
- 平台
- 内容形式
- 奖励金额
- 最低粉丝数
- 剩余名额
- 交稿截止
- 发布截止

### 3.4 申请任务

入口：`/creator/tasks/[id]`

KOL 需要：

1. 阅读完整 brief。
2. 选择用于发布的社媒账号。
3. 填写轻量申请说明。
4. 提交申请。

申请限制：

- 账号平台必须和任务平台一致。
- 粉丝数必须达到最低要求。
- 默认账号必须已验证。
- 同一个 Campaign 默认只能申请 1 个任务。

提交后等待商家审核。

### 3.5 查看我的任务

入口：`/creator/my-tasks`

KOL 可以查看：

- 已申请任务
- 已通过任务
- 草稿状态
- 发布状态
- 验收状态
- 结算状态

### 3.6 提交内容草稿

入口：`/creator/content-studio/[applicationId]`

KOL 需要提交结构化内容：

- 标题
- 脚本/正文
- Caption
- Hashtag
- 封面文字
- 广告披露位置和方式
- 可选成品预览附件

附件限制：

- 默认 50MB。
- 不转码。
- 上限可由 Admin 配置。

广告披露：

- 所有付费任务必须披露广告。
- KOL 必须显性确认披露位置。

提交后：

- 如果 Campaign 需要审稿，等待商家审核。
- 如果不需要审稿，直接进入发布阶段。

### 3.7 根据反馈修改草稿

如果商家要求修改：

1. KOL 在任务详情或内容工作台查看修改原因。
2. 修改结构化草稿。
3. 再次提交。

限制：

- 最多 2 轮修改。
- 超过后需要商家或平台进一步处理。

### 3.8 提交发布链接

入口：`/creator/my-tasks/[id]`

KOL 在草稿通过后提交：

- 发布链接
- 发布时间

第一版不需要提交：

- 截图
- 浏览量
- 点赞量
- 评论量
- 转化数据

系统会做基础平台链接校验：

- 小红书链接应匹配小红书域名。
- 抖音链接应匹配抖音域名。
- 视频号、B站、微博同理。

注意：

- 发布链接必须可访问。
- 链接失效、删除、不可访问或设为私密，默认由 KOL 负责。
- 如果商家拒绝验收，KOL 可以在截止时间前补交多次。

### 3.9 查看钱包和提现

入口：`/creator/wallet`

KOL 可以查看：

- 预计收入
- 待审核收入
- 已入账收入
- 可提现余额
- 冻结金额
- 收益流水
- 提现记录

提现规则：

- 第一版只支持人民币。
- 默认最低提现金额为 ￥20，可由 Admin 配置。
- 提现申请由 Admin 人工处理。

提现步骤：

1. 填写提现金额。
2. 选择收款方式。
3. 填写收款信息。
4. 提交申请。
5. 金额进入冻结状态。
6. Admin 处理后变为已支付或被拒绝。

## 4. Admin 操作流程

### 4.1 审核社媒账号

入口：`/admin/social-accounts`

Admin 可以按状态和平台筛选账号。

审核时重点看：

- 账号链接是否真实。
- 平台是否匹配。
- 账号名称是否合理。
- 粉丝数和平均播放量是否明显异常。

可执行：

- 通过
- 拒绝
- 退回待审核

第一版审核对象是社媒账号，不是 KOL 个人身份。

### 4.2 确认商家付款

入口：`/admin/payments`

Admin 可以查看：

- 商家付款记录
- 待确认账单
- 付款凭证
- 商家余额流水

处理流程：

1. 查看付款凭证。
2. 人工确认金额。
3. 确认后金额进入商家余额。
4. 如果 Campaign 等待托管且余额足够，系统冻结托管金额并发布 Campaign。

注意：

- 第一版只做付款记录和平台收据。
- 不做正式发票流程。

### 4.3 处理 KOL 收益结算

入口：`/admin/payments`

当商家验收通过后：

- 系统生成待处理的 KOL 收益流水。
- Admin 确认后，金额进入 KOL 可提现余额。

Admin 可以：

- 查看收益入账记录
- 查看钱包流水
- 查看关联任务和 Campaign

### 4.4 处理提现申请

入口：`/admin/payments`

提现状态：

- PENDING：待处理
- APPROVED：已批准
- PAID：已打款
- REJECTED：已拒绝

处理规则：

- 批准或支付后，系统更新钱包金额。
- 拒绝后，冻结金额退回可提现余额。
- Admin 应填写处理备注。

### 4.5 处理争议

入口：`/admin/disputes`

争议来源：

- 商家拒绝验收后转入争议。
- SLA 超时且金额较高时自动进入平台复核。
- Admin 手动从发布链接创建争议。

Admin 判断依据：

- Campaign brief
- 任务结构化要求
- KOL 草稿
- 商家审稿记录
- 发布链接
- 验收拒绝原因
- 系统内提交时间和状态

第一版不接受站外聊天作为主要证据。

可做处理：

- 全额结算给 KOL
- 全额退回商家余额
- 部分结算
- 允许 KOL 补交

### 4.6 运行 SLA 自动处理

入口：`/admin/settings`

Admin 点击“运行 SLA 处理”后：

- 系统扫描逾期未验收的发布链接。
- 低金额任务自动通过并直接进入 KOL 可提现余额。
- 高金额任务进入平台争议处理。

注意：

- 第一版是手动触发，不是后台定时任务。
- 后续生产化可以改为定时任务。

### 4.7 配置平台规则

入口：`/admin/settings`

可配置：

- 商家验收 SLA
- 高金额复核阈值
- KOL 补交宽限期
- 最低提现金额
- KOL 预览附件上限
- 平台服务费率
- 平台联系邮箱
- 风险行业关键词
- 风险行业软提示

入口：`/admin/compliance`

可维护：

- 敏感词
- 禁止表达
- 广告披露规则
- 平台规则

### 4.8 查看报表和财务流水

入口：

- `/admin/reports`
- `/admin/payments`
- `/api/admin/finance.csv`

Admin 可以查看：

- Campaign 履约状态
- 平台任务状态
- 商家账单
- 商家余额流水
- KOL 钱包流水
- 提现记录
- 退款记录

## 5. 关键状态说明

### 5.1 Campaign 状态

- DRAFT：草稿
- AWAITING_PAYMENT：等待付款或托管
- ACTIVE：已上架，可申请
- PAUSED：暂停新申请
- COMPLETED：已完成
- CANCELLED：已取消
- ARCHIVED：已归档

### 5.2 KOL 申请状态

- APPLIED：已申请，等待商家审核
- APPROVED：已通过，进入履约
- REJECTED：已拒绝
- CANCELLED：已取消

### 5.3 草稿状态

- NOT_SUBMITTED：未提交
- SUBMITTED：已提交，等待审核
- REVISION_REQUESTED：要求修改
- APPROVED：已通过
- REJECTED：已拒绝

### 5.4 发布链接状态

- PENDING_PUBLICATION：等待发布
- LINK_SUBMITTED：已提交链接
- RESUBMITTED：已补交链接
- ACCEPTED：已验收
- REJECTED：被拒绝
- DISPUTED：进入争议
- EXPIRED：已过期

### 5.5 结算状态

- ESCROWED：已托管
- PAYABLE：可结算
- PAID_TO_WALLET：已入 KOL 钱包
- REFUNDED：已退款
- PARTIALLY_SETTLED：部分结算
- CANCELLED：已取消

## 6. 推荐演示流程

如果要完整演示平台，可以按下面顺序操作：

1. Admin 登录，确认平台配置。
2. KOL 登录，补充资料并提交社媒账号。
3. Admin 审核 KOL 社媒账号。
4. 商家登录，创建 Campaign。
5. 商家余额不足时，在账单页上传付款凭证。
6. Admin 确认付款，Campaign 上架。
7. KOL 在任务大厅申请任务。
8. 商家在 Campaign 详情页通过申请。
9. KOL 提交内容草稿。
10. 商家审稿，通过或要求修改。
11. KOL 提交发布链接。
12. 商家验收通过。
13. Admin 确认 KOL 收益入账。
14. KOL 发起提现。
15. Admin 处理提现。
16. 商家查看 Campaign 报表，Admin 导出财务流水 CSV。

## 7. 当前 V1 限制

当前版本可以用于本地测试和业务演示，但还不是完整生产版。

已知限制：

- SLA 自动处理目前由 Admin 手动触发，不是定时任务。
- Campaign 编辑锁定、版本记录、暂停/取消/退款规则仍需继续完善。
- 部分旧页面仍有历史文案和旧流程残留。
- 正式上线前需要配置生产数据库备份、对象存储、日志、安全策略和部署环境。
- 第一版只支持人民币。
- 第一版不做复杂算法评分，不做复杂模板市场，不做正式发票流程。
